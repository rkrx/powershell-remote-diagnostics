# Encrypted gRPC server and local MCP client

The Windows server retains its embedded PowerShell 7 engine, persistent session, FIFO execution, console approvals/colors, production/test declarations, UUIDs, 15-second wait and last-20 output retention/search. Replace REST entirely with protobuf gRPC over TLS (HTTP/2). No WinRM.

At startup generate an ephemeral ECDSA server certificate and a 256-bit random access secret. Print a connection URL `grpc://<token>@<host>:<port>`; the opaque versioned token contains the secret and SHA-256 certificate fingerprint. The client pins that exact certificate (and checks its validity) before sending the secret as call metadata. Never disable verification indiscriminately, log tokens, accept plaintext, or automatically retry execution. TLS 1.2 remains available for Windows Server 2016 and Windows 10 Pro 22H2.

The local self-contained client exposes MCP over stdio. A `connect` tool accepts an optional connection URL; a complete supplied URL connects without GUI. Missing URL invokes an Avalonia input dialog through a separate client UI subprocess. Invalid/failed supplied URLs report sanitized errors, with no unexpected GUI. The dialog uses a private inherited pipe for its result; credentials are never command-line arguments or written to files. MCP stdout contains only protocol messages; logs go to stderr. Closing the dialog cancels connection. UI entry is desktop-only; direct URLs work headlessly.

MCP tools cover connection, server instructions/environment, execution, status, output paging/long lines, search and cancellation. Local connection IDs and remote execution UUIDs distinguish targets. Server approvals remain server-side. A connection is retained only after authenticated server-info succeeds. Client disconnect does not implicitly cancel remote work.

GitHub releases publish separate self-contained Windows server and client ZIPs and a macOS arm64 client archive. The client does not ship a PowerShell engine. Keep public code/docs English and generic, with no local environment data. Private companion documentation remains outside Git.
